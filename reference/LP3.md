# LP3 distribution quantities

p/d/q/r functions for the Log Pearson Type III distribution.

## Usage

``` r
dlpearson3(x, meanlog, sdlog, skew)

qlpearson3(p, meanlog, sdlog, skew)

plpearson3(q, meanlog, sdlog, skew)

rlpearson3(n, meanlog, sdlog, skew)
```

## Arguments

- x, q:

  Vector of quantiles/magnitudes.

- meanlog, sdlog, skew:

  Parameters.

- p:

  Vector of probabilities.

- n:

  Number of observations to draw.
